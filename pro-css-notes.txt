Do CSS layers impact inheritance?

No, CSS layers do not affect inheritance. Inherited properties like color will continue to be inherited from parent elements regardless of the layer structure.

How do CSS cascade layers affect specificity rules between selectors?

CSS cascade layers change how specificity works by prioritizing layer order over selector specificity. A selector in a later layer will override a selector in an earlier layer, even if the earlier selector has higher specificity. For example, an element selector in a later layer will override an attribute selector (which has class-level specificity) in an earlier layer.

Mobile-first	browser default (1 column)	adds 3 columns
Desktop-first	you set 3 columns	undoes it, back to 1

Using margin-top with em values allows larger text elements to automatically create bigger margins, since 1em is relative to the element's font size. This creates better visual hierarchy and proximity—larger headings naturally get more space above them without explicit adjustments. With margin-bottom, the smaller element above would determine the spacing, losing this automatic scaling benefit.

What is the recommended approach when utility classes become insufficient for styling?

When utility classes reach their limit, create a specific class for unique styling needs. This allows for more focused and maintainable CSS, reducing complexity and improving readability.
